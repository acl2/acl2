The paper, ``Translating HOL to ACL2 with Set Theory'' [1], presents a
correctness result in Section 6.  File hol-in-acl2-supplement.pdf in
this directory is a supplement to that paper.  This supplement fleshes
out an argument for the correctness result, which is sketched only
very briefly in that paper, into a more detailed sketch.

The full paper may be made publicly available. especially upon
request.

1. Kaufmann, M., Slind, K.: Translating HOL to ACL2 with set theory.
In: Nipkow, T., Passmore, G., Sultana, N. (eds.) Logic, Computation
and Proof, vol. 16870.  Springer Nature Switzerland (2026)
